# Документация проекта

## Описание

Проект представляет собой серверное приложение на Node.js, которое автоматизирует выполнение задач в веб-игре. Основной функционал включает:

- Автоматизированный вход в игровую систему
- Анализ страниц игры
- Управление миссиями
- Экспедиции
- Мониторинг состояния сессии

## Структура проекта

### Файлы проекта

1. **`analyze-run.js`**
   - Временный скрипт для запуска анализа страниц
   - Использует Playwright для автоматизации браузера
   - Выполняет аутентификацию пользователя
   - Запускает анализ страниц игры

2. **`app/bot-missions.js`**
   - Модуль для управления миссиями
   - Содержит функцию `watchMissions` для мониторинга миссий

3. **`app/expedition.js`**
   - Модуль для управления экспедициями
   - Содержит функцию `startExpedition` для запуска экспедиций

4. **`app/session-manager.js`**
   - Модуль управления сессией пользователя
   - Содержит функцию `ensureLoggedIn` для проверки и восстановления сессии
   - Реализует логику повторных попыток входа

## Технические детали

### Технологии

- **Node.js** - платформа серверного выполнения JavaScript
- **Playwright** - библиотека для автоматизации браузера
- **ES6+** - современный синтаксис JavaScript

### Архитектура

- **Модульная структура** - разделение функциональности на отдельные модули
- **Асинхронный код** - использование async/await для обработки асинхронных операций
- **Обработка ошибок** - структурированная обработка исключений

## Использование

Для запуска проекта выполните:

```bash
npm install        # postinstall автоматически установит chromium
npm start          # = node serverXG.js
```

Переменные окружения:

| Переменная | Значение | Описание |
|---|---|---|
| `HEADLESS` | `1`/`0` | Режим браузера. Не задан → авто (headless, если нет `DISPLAY`) |
| `PORT` | число | Если задан — поднимается health-сервер на `/health` (нужно для Render) |

Ошибки пишутся в консоль и в корневой файл `.errors` (см. `app/logger.js`).

## Деплой на Render.com

1. Запушьте репозиторий на GitHub.
2. На Render: **New → Blueprint** → выберите репозиторий. Blueprint берёт `render.yaml` из корня.
3. Готово: сборка (`npm install` + системные зависимости chromium) и запуск (`npm start`, `HEADLESS=1`).

Особенности:

- **Браузер headless** — на Render нет дисплея, поэтому браузер запускается без UI.
- **Health-эндпоинт** — Render Web Service требует открытый порт; бот слушает `$PORT` и отвечает на `/health` (статус + последний тик).
- **Файловая система эфемерная** — `session.json` и `data/bot-state.json` сбрасываются при редеплое/рестарте. Бот автоматически перелогинивается по креденшелам из `config.json`, так что это не критично.
- **Бесплатный тариф** спинаунит web-сервис после ~15 минут без трафика — для 24/7 бота нужен платный инстанс (Starter, $7/мес).
- Все данные в `config.json` — тестовые (опенсорс-проект), секреты намеренно не скрываются.
